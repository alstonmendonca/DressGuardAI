# WhatsApp Integration Setup Guide

This guide explains how to set up WhatsApp notifications for DressGuard violation reports using Twilio.

## 📋 Prerequisites

1. A Twilio account (free trial available)
2. Python environment with Twilio package installed
3. A phone number capable of receiving WhatsApp messages

---

## 🚀 Setup Steps

### 1. Install Twilio Package

```bash
pip install twilio==9.3.7
```

Or install from requirements.txt:
```bash
pip install -r requirements.txt
```

### 2. Get Twilio Credentials

1. **Sign up for Twilio**
   - Go to [https://www.twilio.com/try-twilio](https://www.twilio.com/try-twilio)
   - Create a free account (trial includes $15 credit)

2. **Find Your Credentials**
   - After logging in, go to your [Twilio Console](https://console.twilio.com/)
   - Copy your **Account SID** (starts with "AC...")
   - Copy your **Auth Token** (click "Show" to reveal it)

3. **Set Up WhatsApp Sandbox**
   - Go to [WhatsApp Sandbox](https://console.twilio.com/us1/develop/sms/try-it-out/whatsapp-learn)
   - Follow instructions to activate WhatsApp on your phone
   - Send the provided code to the Twilio WhatsApp number
   - Note the **Twilio WhatsApp number** (e.g., `+14155238886`)

### 3. Configure DressGuard

Open `config.py` and update the following settings:

```python
# ============================================================================
# WhatsApp Integration (Twilio)
# ============================================================================

# Twilio Credentials - REPLACE WITH YOUR ACTUAL VALUES
TWILIO_ACCOUNT_SID = "AC_REDACTED_TWILIO_SID_PLACEHOLDER"  # Your Account SID
TWILIO_AUTH_TOKEN = "your_actual_auth_token_here"          # ⚠️ REPLACE THIS
TWILIO_WHATSAPP_FROM = "whatsapp:+14155238886"             # Twilio sandbox number

# Default recipient numbers for reports (in E.164 format)
WHATSAPP_RECIPIENTS = [
    "+919108816244",      # Replace with your phone number
    # "+911234567890",    # Add more recipients as needed
]
```

**Important Notes:**
- Replace `"your_actual_auth_token_here"` with your actual Twilio Auth Token
- Phone numbers must be in **E.164 format**: `+[country code][number]`
  - Example: India `+919108816244`, US `+15551234567`
- For **Twilio Free Trial**, you can only send to verified phone numbers
  - Verify numbers in [Twilio Console → Phone Numbers → Verified Caller IDs](https://console.twilio.com/us1/develop/phone-numbers/manage/verified)

### 4. Test the Integration

1. **Start the Backend**
   ```bash
   cd DressGuard
   uvicorn main:app --reload
   ```

2. **Start the Frontend**
   ```bash
   cd frontend
   npm run dev
   ```

3. **Send Test Alert**
   - Log some violations by enabling "Start Logging" and "Face Detection ON"
   - Click the **"Send Alerts"** button in the Actions panel
   - You should receive a WhatsApp message with the report summary

## 📱 Features

### 1. Send Alerts Button (Actions Panel)
- Automatically sends WhatsApp notifications for today's violations
- Shows violation count and recipient status
- Only works when WhatsApp is configured and enabled

### 2. Generate Report Modal
- Generate Excel report for any date
- Send report notification via WhatsApp button
- Choose custom recipients or use defaults from config

## 🔧 Troubleshooting

### Error: "WhatsApp integration not configured"
- Check that `TWILIO_ACCOUNT_SID` and `TWILIO_AUTH_TOKEN` are set in `config.py`
- Ensure credentials are valid (no extra spaces or quotes)
- Restart the backend server after changing config

### Error: "Twilio error: Unable to create record"
- Verify the recipient phone number is in E.164 format (`+countrycode number`)
- For trial accounts, verify the recipient number in Twilio Console
- Check that WhatsApp sandbox is activated

### Message Not Received
- Ensure you've sent the join code to activate the WhatsApp sandbox
- Check the phone number format (include country code with +)
- Verify there are violations logged for the selected date
- Check Twilio Console logs for delivery status

### Button is Grayed Out
- WhatsApp is not configured or disabled
- Set up credentials in `config.py`
- Restart the backend to reload configuration

## 🔒 Security Best Practices

1. **Never commit your Auth Token to Git**
   - Add `.env` file support if sharing code
   - Use environment variables in production

2. **Rotate Auth Token regularly**
   - Generate new tokens in Twilio Console
   - Update `config.py` after rotation

3. **Restrict recipient numbers**
   - Only add authorized personnel to `WHATSAPP_RECIPIENTS`
   - Validate phone numbers before sending
